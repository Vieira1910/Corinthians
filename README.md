# ⚫⚪ CORINTHIANS — SITE INSTITUCIONAL ESPORTIVO

Desenvolvimento de um site institucional esportivo dedicado ao **Sport Club Corinthians Paulista**, criado com o objetivo de destacar a história, a identidade, as conquistas e a paixão da torcida corinthiana por meio de uma experiência digital moderna, interativa e visualmente impactante.

O projeto foi desenvolvido utilizando **HTML5, CSS3 e JavaScript (JS)**, com foco na identidade visual do clube, na organização das informações, na interatividade e na experiência do usuário.

---

## 🛠️ TECNOLOGIAS UTILIZADAS

- **HTML5**
- **CSS3**
- **JavaScript (JS)**

---

## ⚽ FUNCIONALIDADES

- Apresentação do Sport Club Corinthians Paulista
- Seções dedicadas à história e à trajetória do clube
- Destaque para conquistas e momentos históricos
- Identidade visual inspirada nas cores tradicionais do Corinthians
- Layout estruturado com HTML semântico
- Estilização personalizada utilizando CSS3
- Elementos interativos desenvolvidos com JavaScript
- Utilização e organização de imagens esportivas
- Interface visual moderna, responsiva e imersiva
- Navegação e interações para proporcionar uma experiência mais dinâmica

---

## 🎯 OBJETIVOS DO PROJETO

O projeto teve como principais objetivos:

- Praticar a estruturação de páginas com **HTML5**
- Desenvolver layouts personalizados utilizando **CSS3**
- Aplicar **JavaScript** para adicionar interatividade à interface
- Trabalhar com identidade visual e composição de elementos esportivos
- Criar uma experiência digital que represente a história e a paixão corinthiana
- Desenvolver uma interface moderna, organizada e visualmente marcante
- Aplicar conceitos de **Desenvolvimento Front-End** na criação de um projeto temático

---

## 📚 APRENDIZADOS

Durante o desenvolvimento do projeto, foram praticados conceitos importantes de Front-End:

- Estruturação semântica com **HTML5**
- Estilização e criação de layouts com **CSS3**
- Manipulação de elementos e interações com **JavaScript**
- Organização de seções e componentes visuais
- Utilização e posicionamento de imagens
- Hierarquia visual e identidade de marca
- Criação de interfaces interativas para a Web
- Integração entre HTML, CSS e JavaScript
- Desenvolvimento de uma experiência visual alinhada à proposta do projeto

---

## 👨‍💻 DESENVOLVIMENTO

Projeto desenvolvido como prática de **Desenvolvimento Front-End**, colocando em prática conhecimentos de **HTML5, CSS3 e JavaScript** na criação de um site esportivo dedicado ao Corinthians.

Mais do que apresentar informações sobre o clube, o projeto busca transformar a identidade alvinegra em uma experiência digital envolvente, valorizando a história, as conquistas e a conexão entre o Corinthians e sua torcida.
